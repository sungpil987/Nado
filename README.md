# 냥도쿠 (Nyangdoku)

고양이가 서로 이웃하지 않도록 놓는 색 구역 퍼즐 게임입니다. 행마다 한 마리, 열마다 한 마리, 같은 색 구역에 한 마리, 그리고 고양이끼리 인접하지 않게 배치합니다.

## 플레이

- 빈칸을 한 번 눌러 X 표시, 빠르게 두 번 눌러 고양이를 둡니다.
- 레벨이 오르면 12레벨마다 보드가 한 칸씩 커집니다. 현재 생성기는 4×4부터 9×9까지 무한 레벨을 지원합니다.
- 진행과 점수는 기기에 저장됩니다.
- 다음 레벨 진입 시 강제 광고는 없습니다. 힌트가 없을 때만 선택형 보상 광고를 요청합니다.

## 빌드

Android Studio에서 열거나, JDK 17과 Gradle 8.13으로 `gradle assembleDebug`를 실행합니다. GitHub Actions는 debug APK를 빌드해 `nyangdoku-debug-apk` 아티팩트로 저장합니다.

개발 중에는 Google 테스트 앱 ID와 테스트 보상형 광고 단위를 사용합니다. Play 스토어 출시 전에는 AdMob 앱 ID와 광고 단위를 본인 계정의 실제 값으로 교체하고 동의/개인정보 공개 설정을 완료해야 합니다.
