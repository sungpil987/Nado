# 냥도쿠 (Nyangdoku)

고양이가 서로 이웃하지 않도록 놓는 색 구역 퍼즐 게임입니다. 행마다 한 마리, 열마다 한 마리, 같은 색 구역에 한 마리, 그리고 고양이끼리 인접하지 않게 배치합니다.

## 플레이

- 빈칸을 한 번 눌러 바로 X 표시, 누른 채 드래그해 여러 칸에 X를 연속 표시할 수 있습니다. 같은 칸을 빠르게 두 번 눌러 고양이를 둡니다. 오답 기회는 스테이지마다 3회입니다.
- 첫 실행은 4×4 튜토리얼과 고정 고양이 2마리로 시작합니다. 4×4는 10레벨, 5×5는 15레벨, 6×6은 20레벨, 7×7은 25레벨, 8×8은 30레벨 동안 유지한 뒤 9×9로 커져 급격한 난이도 상승을 늦췄습니다. 같은 크기 안에서는 진행도에 따라 고정 힌트 고양이가 단계적으로 줄어듭니다.
- 각 스테이지는 고유한 색 구역, 정답 배치, 고정 고양이 위치·개수로 생성되며, 저장된 스테이지를 다시 열어도 배치가 유지됩니다. 퍼즐은 주어진 힌트 기준으로 해답이 하나가 되도록 생성합니다.
- 고정 힌트 고양이는 움직이거나 지울 수 없습니다.
- 데일리 챌린지는 한국 시간 달력으로 날짜별 퍼즐을 기록하고, 지난 날짜 플레이와 월간 트로피를 지원합니다. 플레이 진행도와 최근 실수 수로 데일리 난이도를 조정합니다.
- 스테이지를 완료하면 고양이 팝 애니메이션과 종이 폭죽 효과가 재생됩니다.
- 진행과 점수는 기기에 저장됩니다.
- 다음 레벨 진입 시 강제 광고는 없습니다. 힌트가 없을 때만 선택형 보상 광고를 요청합니다.

## 빌드

Android Studio에서 열거나, JDK 17과 Gradle 8.13으로 `gradle assembleDebug`를 실행합니다. GitHub Actions는 debug APK를 빌드해 `nyangdoku-debug-apk` 아티팩트로 저장합니다.

개발 중에는 Google 테스트 앱 ID와 테스트 보상형 광고 단위를 사용합니다. Play 스토어 출시 전에는 AdMob 앱 ID와 광고 단위를 본인 계정의 실제 값으로 교체하고 동의/개인정보 공개 설정을 완료해야 합니다.
